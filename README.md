#  PlantEvo Viewer
**PlantEvo Viewer** est un site web éducatif réalisé dans le cadre du Brief 1 de la Digital Farming School (DFS). Il présente l'évolution des végétaux à travers six grandes étapes, depuis les algues aquatiques jusqu'aux dicotylédones. L'application permet de découvrir les caractéristiques des différents groupes végétaux, leurs adaptations à la vie terrestre, leurs modes de reproduction et les innovations qui ont marqué leur évolution. Elle propose une frise chronologique, des pages explicatives illustrées pour chaque groupe, une présentation des quatre grands défis de la vie terrestre (se dessécher, tenir debout, se reproduire et disperser les graines), ainsi qu'un exemple agricole ivoirien consacré à la pollinisation du cacaoyer. Le site intègre également des observations réalisées sur la ferme-école et une carte des relevés GPS par groupe végétal. **Technologies utilisées :** HTML5 pour la structure des pages et CSS3 pour la mise en forme, les animations et les effets visuels. **Structure :** `index.html` constitue la page d'accueil, tandis que `algues.html`, `mousses.html`, `fourgeres.html`, `coniferes.html`, `graminees.html` et `dicotyledones.html` présentent les différents groupes végétaux. Les fichiers CSS sont organisés dans le dossier `css/` et les illustrations dans le dossier `images/`. **Installation :** télécharger le projet, ouvrir le dossier dans Visual Studio Code et lancer `index.html` dans un navigateur ou utiliser l'extension Live Server. **Formation :** Digital Farming School (DFS) – **Projet :** Brief 1 – **Année :** 2026.
